# Hadoop Basics

## Overview
Hadoop is an open-source framework used to store and process large volumes of data across multiple computers.

## Key Components

### HDFS
Stores data across multiple machines and provides fault tolerance.

### MapReduce
Processes large datasets using distributed computing.

### YARN
Manages cluster resources and schedules jobs.

### Hadoop Common
Provides shared libraries and utilities for Hadoop.

## Features
- Distributed Storage
- Fault Tolerance
- Scalability
- Parallel Processing
